# Коробка-приёмник (реальный стенд)

Печатный двойник сим-коробки из `mlsim/models/so101/pick_place.xml`:
внешний след **110×110 мм, борт 8 мм, высота 44 мм, дно 8 мм** — один в один
с симом, потому что эти числа входят в критерий успеха
(`mlsim/criteria.py`: верх борта 0.044 м, кубик на дне z = 0.022 м).
Менять габариты = менять протокол оценки.

В дне — карман под ArUco-вкладыш **DICT_4X4_50 id 16** (маркер 60 мм,
клетка 10 мм): по метке CV-стенд узнаёт позу коробки той же верхней
камерой, что ведёт кубы. Это нужно алгоритмическому опусканию кубика.
Кубик, лежащий в коробке, метку закрывает — позу коробки надо снимать в
начале сессии, пока она пуста (коробка статична). `MARKER = False` в
`make_box.py` даёт гладкое дно.

Генератор: `python3 make_box.py` → `out/` (самопроверка детекцией внутри).

| Файл | Что это |
|---|---|
| `bin_2color.3mf` | вся коробка одной моделью для Bambu/AMS: тело — филамент 1, метка — филамент 2 |
| `bin_body.stl` | тело с карманом в дне (для одноцветной печати) |
| `bin_marker_inlay.stl` | чёрный вкладыш метки, лежит лицом ВНИЗ — печатать как есть |
| `preview_bin.png` | вид дна с меткой и габариты |
| `manifest.json` | габариты + поза метки в системе коробки (для CV-кода) |

## Печать

- ~217 см³ тела: при 3 периметрах и 15 % заполнения ≈ 95 г PLA.
  Печать дном вниз, поддержки не нужны.
- Цвета: тело — светлое (белый матовый как у кубов — лучший контраст метки),
  вкладыш — чёрный матовый. Цвет коробки в симе синий, но для реального
  датасета важна геометрия, а не цвет (политика реала учится на реальных
  кадрах); хотите синюю — печатайте тело синим, метка на дне всё равно
  чёрно-белая за счёт белых клеток кармана.
- Однотонный принтер: печатать `bin_body.stl` + `bin_marker_inlay.stl`
  отдельно, вкладыш вклеить (зазор 0.2 мм на сторону, «слоновью ногу»
  компенсировать в слайсере, как у кубов).
