# GripperAR — iPhone как схват (ARKit → телеоперация SO-101)

Нативное приложение: ARKit даёт положение и поворот телефона 60 раз в секунду, приложение
шлёт смещение относительно якоря в тот же WebSocket `real/teleop/web_teleop.py` (режим `xr`,
как страница `/xr` на Android), показывает камеру кисти, ползунок схвата и подсветку границы зоны.

## Сборка (Mac с Xcode 15+, iPhone с iOS 16+)

1. Xcode → File → New → Project → iOS → App. Product Name `GripperAR`, Interface SwiftUI,
   Language Swift. Сохранить куда угодно.
2. В навигаторе удалить созданные `GripperARApp.swift` и `ContentView.swift`, перетащить
   в проект шесть файлов из этой папки (`GripperARApp.swift`, `ContentView.swift`, `ARPose.swift`,
   `Teleop.swift`, `MJPEGView.swift`, `GlowOverlay.swift`), галочка «Copy items if needed».
3. Target → Info → добавить ключ `Privacy - Camera Usage Description` (NSCameraUsageDescription):
   «Камера нужна для отслеживания положения телефона».
4. Signing & Capabilities → Team: ваш Apple ID (бесплатной подписи хватает, приложение живёт 7 дней,
   потом пересобрать). Подключить iPhone кабелем, выбрать его как устройство, Run.
5. На iPhone: Настройки → Основные → VPN и управление устройством → доверять разработчику.

## Использование

Старт: ввести адрес сервера (`https://…trycloudflare.com`, без косой черты в конце) и ключ `k`.
«Старт» → камера кисти на экране. Держать телефон экраном к себе, задней камерой «вперёд»,
нажать «Следовать»: поза в этот момент — якорь, дальше схват повторяет смещения телефона 1:1
и поворот вокруг вертикали. «Следовать» ещё раз — рука замирает, телефон можно переложить.
Ползунок — схват. Рамка краснеет с той стороны, куда рука больше не может; полоска справа —
потолок и пол. Строка сверху — координаты, угол, связь, сообщения охраны, состояние трекинга ARKit
(если «ограничен» — поводите телефоном, чтобы ARKit увидел текстуру).

Наклоны телефона (pitch/roll) пока не передаются: схват подходит сверху.
